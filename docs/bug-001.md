# 缺陷案例 BUG-001：商品接口接受空 SKU 或空商品名

## 基本信息

- 缺陷编号：BUG-001
- 模块：商品管理
- 严重程度：中
- 优先级：高
- 状态：已修复并回归通过

## 复现步骤

管理员登录后调用：

```http
POST /products
Content-Type: application/json

{"sku":"   ","name":"有效名称","price":1,"stock":1}
```

## 修复前结果

接口返回 `200`，数据库中写入空 SKU。商品名称只包含空格时也会被接受。空标识会影响商品查询、重复校验和后续订单追踪。

## 预期结果

SKU 和商品名称去除首尾空格后不能为空；非法请求应返回 `400`，且数据库不新增商品。

## 原因分析

原实现只校验字段类型，没有校验 `strip()` 后的字符串是否为空。

## 修复方案

在写入数据库前统一清洗 SKU 和商品名称，并增加非空判断；审计日志使用清洗后的 SKU。

## 回归验证

新增 `test_product_rejects_blank_sku_or_name`，分别验证空 SKU 和空商品名，预期均返回 `400`。完整回归测试通过后关闭缺陷。
